Task 3: Semantic vs Non-Semantic Tags

Semantic Tags (Meaningful Tags)

In tags ka apna aik matlab hota hai, jo browser aur search engine ko batata hai keh content kya hai.

  • <header> - Page ka top header section
  • <nav> - Navigation links ka area
  • <main> - Main content area
  • <article> - Independent content/article
  • <section> - Content ka specific part
  • <footer> - Page ka bottom area

Non-Semantic Tags (Generic Tags)

In tags ka koi khas matlab nahi hota, yeh sirf styling aur grouping ke liye istemal hotay hain.

  • <div> - Block-level container
  • <span> - Inline container
  • <b> - Sirf text ko bold karne ke liye
  • <i> - Sirf text ko italic karne ke liye
