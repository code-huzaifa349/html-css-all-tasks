1. Introduction

The CSS Box Model explains how every HTML element is displayed as a rectangular box. It describes the space occupied by an element on a web page. The Box Model has four parts: content, padding, border, and margin.

Content

The actual text, image, or other information inside an element.

Padding

The space between the content and the border.

Border

The line surrounding the content and padding.

Margin

The space outside the border, separating an element from other elements.

2. Content-box

The default value of box-sizing is content-box. In this model, the width and height apply only to the content. Padding and border are added outside the specified content size, so the total size becomes larger.

3. Border-box

When box-sizing: border-box is used, the specified width and height include the content, padding, and border. The total size stays fixed. When padding or border increases, the content area becomes smaller.

4. Observations

Content-box

When padding and border values increase, the total width and height of the box also increase. The specified width and height apply only to the content area.

Border-box

The total width and height remain fixed at the specified values. When padding and border increase, the available content area becomes smaller.
